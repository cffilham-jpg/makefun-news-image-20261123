One image summing up the world's news of **Monday 23 November 2026**:
Democrats clinch 258 House seats, NATO's Council meets on the Poland
airspace breach, Liverpool rout Pochettino's Manchester United 4–0 —
plus 33 more verified stories, a 6-number strip, a 7-region bar, a
"WHERE IT HAPPENED" map and a DATE CHECK box naming what was *not*
counted as Monday (COP31 collapse, Korea minister, Merkury, India 720,
Kyiv drone strike, UN killer-robot deal, Chapo Isidro, Verstappen).

`main.py` (stdlib only) copies `entry.png` to `MAKEFUN_OUTPUT_DIR`
(with a tempdir fallback) and validates it: PNG, 1024×1024, ≤ 1 MiB.
Both runs write identical bytes.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
